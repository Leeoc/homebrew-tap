# Leeoc's Homebrew tap

```sh
brew trust --cask leeoc/tap/devrings   # Homebrew asks you to trust casks from other people's taps
brew install --cask leeoc/tap/devrings
```

| Cask | What it is |
|---|---|
| [devrings](https://github.com/Leeoc/devrings) | A macOS menu bar app that turns your dev day into rings: ship, review, close tickets. |
